# 独立卡片模板

```markdown
# PIT-YYYYMMDD-short-slug：标题

- 状态：已确认 / 待验证 / 已过时（保留局部限定）
- 建立日期：YYYY-MM-DD
- 最后验证：YYYY-MM-DD（仅实际验证后填写，未知则注明）
- 现象：
- 环境/版本/型号：
- 失败尝试：未记录则注明
- 根因：已证实 / 推测 / 未知
- 解决方案或排查方向：
- 验证证据及未覆盖范围：
- 适用边界：
- 真实来源：
- 关联条目/修订依据：有则填写
```

短索引的 direction 与 scope 是这张卡片的摘要，不能添加正文未证明的结论。关键词同时含常见中文症状与英文错误码/组件名，供本地匹配。
