# Maintenance scenarios

Use these to inspect responses and state transitions after changes. They are manual evaluation material, not automatically passing tests. Record actual responses or walkthrough conclusions and distinguish independent model trials from maintainer review. Give evaluators the scenario and skill, without embedding the criteria as user instructions.

| Scenario input/existing state | Evaluate |
| --- | --- |
| “Just explain metaphor. I don't want a full course.” | Explain with an example; no syllabus, intake questionnaire, or forced exercise |
| “Interview in five days; some Python, little SQL, half an hour each evening. Here is the role description.” | Reuse purpose, level, and time; narrow the route around the role, asking only missing questions that matter; do not invent two hours daily |
| During outer joins: “I don't know NULL; don't go further yet.” | Explain the prerequisite and offer study now/working concept/defer, then wait; do not advance dependent exercises |
| Interview study has become deep networking: “How is this related to the job?” | Explain relevance, trim unnecessary tangents, and offer the next main-route step; do not require a complete networking course |
| “No more quizzes or interview simulations. Explain more fully and continue the last concept.” | Stop practice, continue the current module with adequate detail, leave proficiency unverified, and do not restart intake |
| In literature discussion: “I think this image means something other than sadness, based on the last two lines.” | Discuss textual evidence and supported interpretations without imposing one uniquely correct reading |
| Supplied state: chapter two, one deferred prerequisite, no quizzes; continue. No helper skills are installed. | Resume from supplied state and preserve gaps/preferences; teach in prose without claiming access to other chats or requiring visualization/grill-me |
| “Teach this library for my work project, but don't install anything or edit code; I'll send the textbook later.” | Teach independent parts using available information, without edits or installation; do not block all learning on the missing source, and adapt when it arrives |

Also check retaining valid progress when interest becomes exam preparation, providing a complete example when requested, and not performing dependent steps while waiting for a choice. Teaching outcomes still need observation in actual use.
