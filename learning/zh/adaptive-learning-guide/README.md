# 自适应学习引导

按学习目的和已有水平，通过对话制定、执行和调整学习路线。适用于技术、人文社科、文学、面试和考试；既能持续带学，也能只解释当前不懂的地方。

## 安装与使用

将完整技能文件夹或压缩包交给能访问本机文件的 AI，例如：

```text
帮我安装 <本技能文件夹路径> 中的 skill，先阅读 README.md 和 AI_readme.md。
```

安装 AI 先读本文件、[AI_readme.md](AI_readme.md) 和 [SKILL.md](SKILL.md)，确认宿主是否支持此类技能及实际发现目录；只安装所选语言的完整 `adaptive-learning-guide/`，不要复制 `learning/zh` 等父目录。同名旧版先备份到发现目录外，再替换整个文件夹，保留其他技能。检查安装文件、宿主发现结果，简短给出路径与调用方式；无法验证发现时如实说明。

本技能没有脚本、外部服务或必装的其他技能，不需要创建全局规则。主体指令不依赖 Codex；`agents/openai.yaml` 是可选的宿主界面配置。不同宿主的发现机制与调用语法需分别验证，不能保证复制后在所有产品中自动生效。没有本地文件工具的聊天只能使用提供的指令，不能完成电脑上的安装。

在支持 `$skill-name` 的宿主中可这样调用；其他宿主使用其技能选择方式：

```text
使用 $adaptive-learning-guide 带我学习 SQL。我会一点 Python，想为面试做准备。
```

也可以说“我想了解唐诗，先不做练习”，或在学习中提出“这里不懂”“想深入一点”“先跳过”“回到原计划”。AI 应继承已知信息，分批补问目的、基础、资料和练习偏好，不重复做入门访谈。

## 学习方式

- 先判断是一次解惑还是持续带学，再根据目标和表现安排深度。
- 前置知识缺失时，说明影响，让学习者选择补学、够用概念或暂跳；不默认已经掌握。
- 可以选择纯讲解、实操、问答、复述、写作或模拟面试，也可以关闭练习。
- 兴趣、期限或用途变化时调整路线；支线偏离目标时提醒并给选择。
- 阶段总结区分“讲过”“自述理解”“有练习证据”。默认只在对话中维持进度，保存或跨对话交接按用户要求处理。

学习请求不自动授权修改工程、安装依赖、操作硬件或安排付费服务。其他 skill 可选，缺少时仍独立教学；`adaptive-clarification` 可按其私有记录规则和用户保留偏好维护必要反馈，由学习技能统一提问，避免重复访谈，不自动建立完整学习进度档案。
